# Eight Off

Proyecto Java para implementar el juego de cartas Eight Off.

## Abrir en IntelliJ IDEA

1. Descomprime la carpeta si recibiste el proyecto como ZIP.
2. En IntelliJ, selecciona **File > Open**.
3. Elige la carpeta `EightOff` o su archivo `pom.xml`.
4. Si IntelliJ pregunta, selecciona **Open as Project** y permite que importe Maven.
5. Configura un JDK 17 o posterior como Project SDK.

El código fuente se escribirá en `src/main/java`. Por ahora el proyecto está vacío intencionalmente para que agregues las clases durante la práctica.
